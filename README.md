# huatu-image

小红书账号「口袋里的瑶」的待发布图文素材库。这个仓库只放成品（图片 + 文案），不放生成程序。

## 给发布 AI 的读取规则

- `posts/` 下面**每个文件夹就是一篇笔记**，文件夹名是组编号加主题，比如 `g001_home`。
- 图片按 `01.png`、`02.png`…… 编号，**编号顺序就是发布顺序，`01.png` 永远是封面**。
- 每个文件夹里有一个 `post.md`：
  - 开头的 front matter（`---` 之间）是结构化信息：`title` 标题、`cover` 封面、`images` 图片顺序、`tags` 话题、`status` 状态。
  - 「发布说明」一节说明这组图的题材和场景，**只给发布 AI 参考，不要发出去**。
  - 「正文」一节是**可以直接原样发布的笔记正文**（已经控制在小红书 1000 字以内）。
- `status: ready` 表示可以发布。
- `order` 是发布顺序（g001 是第 1 篇），`suggested_date` 是按每天 1 篇排出的建议发布日期，节日主题（霜降、万圣节、立冬、双十一）已经对齐到对应日期。
- 所有图片都是 AI 生成的，发布时要勾选「内容含 AI 生成」的声明。

## 账号定位

AI 提示词分享号。固定虚拟人物「瑶」（22 岁中国女生）的生活日常组图，主题包括居家、出门、通勤上班、咖啡店、逛街、旅行等。每篇正文附上生成这组图的提示词。
